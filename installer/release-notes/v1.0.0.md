## CVSniper v1.0.0

### Instalación en Windows
1. Instala Google Chrome si no lo tienes.
2. Descarga **CVSniper-Setup-1.0.0.exe** (abajo, en Assets) y ejecútalo.
3. CVSniper aparece en el menú Inicio. No hace falta instalar Python ni nada más.

Para desinstalar: Configuración → Aplicaciones → CVSniper → Desinstalar. Te pregunta si quieres borrar también tus datos (configuración, historial, CVs).

> Si Windows muestra "Windows protegió tu PC", pulsa **Más información → Ejecutar de todas formas** (el instalador no tiene firma digital).

### Novedades
- Ya no se salta ofertas por errores sueltos ni corta toda la ejecución.
- Filtros de experiencia y residencia más precisos, también en español.
- La contraseña de LinkedIn y la API key se guardan en el Administrador de credenciales de Windows.
- Aviso automático cuando sale una versión nueva.
